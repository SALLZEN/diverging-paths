# Version 3.1.0: scope of the update

This is a new execution/presentation version of the retained Diverging Paths evidence. It is prepared from Git commit 965cc43d85349a12c21ce0c1eb3d0d71c3a52651 and the independently packaged DAMADI archive v0.1.1, E.04 computational companion edition 0.1.1.

The earlier Zenodo version 10.5281/zenodo.23263996 remains the scientific baseline. This package is named diverging-paths throughout its active documentation and metadata. The predecessor manifest and citation metadata are preserved under provenance/v3.0.0/; old identifiers inside them identify history, not the current package.

The normalized route shares code/modules/workflow.py between script and notebook, reads the exact six input tables, and checks the retained classification, candidate and graph products. Two large tables are supplied as lossless transport parts; automatic restoration recovers the exact original bytes. The existing network ZIPs are reused in place, avoiding duplicate archives.

The corpus and candidate calculations and network-metric helpers retain the approved archive's mathematical statements. Network manifest lookup is adapted to the preserved predecessor manifest. No fresh acquisition, extraction, annotation, bootstrap resampling, model choice or ontology change is part of this release.

The author-designated later stepwise R source supplies the current main-figure presentation. fonts, class colors and export dimensions match the approved archive. Main figures are 165 x 90 mm and twice 156 x 80 mm. Nine normalized manuscript references are under figures/normalized/. Four statistical SI reference PDFs remain exact retained artwork; regenerated SI companions remain distinct. Original v3.0.0 figure assets are preserved at their original paths.

Full graphical execution is certified on macOS with Quartz, R and command-line compiler support. Numerical-only modes skip graphics and do not need R. Other operating systems have not been newly certified.

The existing root configure_repo.sh and bootstrap_python_env.sh now call setup-environment.sh for the normalized environment. install_repo_kernel.sh is optional; the preferred notebook runner creates its own private kernel. The older upstream extraction/statistical environment under code/ remains separate.
